# 🙏 Light Church - Plateforme pour Pasteurs

## Site de Démonstration Commercial

Site web professionnel ciblant les **pasteurs et responsables d'églises** pour promouvoir la plateforme d'administration Light Church.

---

- Mesurer leur impact avec des statistiques
- **Participer au réveil spirituel**

## 🔧 Personnalisation

### Ajouter de vrais témoignages:
Modifiez la section `#temoignages` dans `index.html` lignes 450-520

### Changer les statistiques:
Mettez à jour les chiffres dans:
- Hero stats (lignes 50-75)
- Mission cards (lignes 180-210)
- Dashboard preview (lignes 120-135)

### Connecter au backend:
Dans `script.js`, fonction `showDemoModal()` ligne 200:
```javascript
// Envoyer les données à votre API
fetch('/api/pastors/signup', {
    method: 'POST',
    body: JSON.stringify(formData),
    headers: { 'Content-Type': 'application/json' }
});
```

### Ajouter une vraie vidéo:
Dans `script.js`, fonction `showVideoDemo()` ligne 300:
```javascript
// Remplacer le placeholder par:
<iframe
    src="https://www.youtube.com/embed/YOUR_VIDEO_ID"
    frameborder="0"
    allowfullscreen>
</iframe>
```
