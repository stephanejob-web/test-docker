PROBLÈME IDENTIFIÉ
═══════════════════════════════════════════════════════════════════════════════

Dans /dashboard/admin/events :
- TOUS les événements s'affichent avec le statut "À venir" (UPCOMING)
- Les événements passés ne s'affichent PAS comme "Terminé" (COMPLETED)
- Les filtres par statut ne fonctionnent pas correctement

CAUSE:
Le frontend RECALCULE le statut côté client et ÉCRASE le bon statut retourné
par le backend. Le calcul côté frontend est incorrect (problème de parsing
des dates).

═══════════════════════════════════════════════════════════════════════════════
SOLUTION
═══════════════════════════════════════════════════════════════════════════════

Utiliser le statut calculé par le BACKEND (comme dans MyEvents.tsx) au lieu
de le recalculer côté frontend.

POURQUOI ÇA MARCHE:
- Le backend calcule correctement le statut (testé avec les événements "test")
- L'API /admin/events retourne déjà les événements avec le bon statut
- MyEvents.tsx utilise cette même approche et ça fonctionne parfaitement
